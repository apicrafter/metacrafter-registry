# Archive

Read-only material kept for history. Nothing here is part of the build, and
nothing here is maintained.

- `original/` - the original CSV source of the registry (2022), before the
  move to one YAML file per record.
- `analysis/` - research notes on other semantic-type tools (DataHub,
  Sherlock).
- `scripts/` - one-off scripts used to analyse metacrafter-rules coverage and
  to bulk-create records (2025-2026). They predate the v2 record contract
  and do not produce valid records any more. The maintained generator is
  `scripts/generate_missing_entries.py`.
