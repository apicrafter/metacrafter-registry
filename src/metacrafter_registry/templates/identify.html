Identify values

Paste sample values from one column, one per line, and optionally the column name. The page ranks registry datatypes by how many values match their regular expression, whether check digits are valid (Luhn, IBAN, ISBN, INN, …) and how close the column name is.

Your values stay in this browser tab. Matching runs locally; the page only downloads the datatype index. Even so, prefer test or masked values over real personal data.

How the score works

Score (0–100) = 60 × share of values matching the regexp × regexp specificity + 25 × share of valid check digits + 25 × column-name similarity; +5 for a matching country, −10 for another country, −5 for draft records. Specificity is low for catch-all patterns that also match many other datatypes’ examples. The same formula is used by the Python package and the MCP server.
