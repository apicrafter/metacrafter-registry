Registry vocabulary

The terms that the RDF exports use for facts that SKOS, Dublin Core and RDFS have no term for: regular expressions, check digits, the PII flag, status and tools.

Namespace {{ namespace }}, prefix mcr:. The OWL declaration is /vocab.ttl. The terms are used in the concept scheme /registry.ttl and in the Turtle file of each record, /datatype/<id>.ttl. Terms are added, never removed or renamed.

Standard terms

Other facts use standard terms:

  • skos:example: a value that matches the datatype (negative examples are not exported)
  • skos:exactMatch: the same concept in Wikidata, Schema.org, FIBO, Bioregistry, FHIR or D3M
  • skos:broadMatch: the DPV personal-data category
  • dcterms:spatial: a country page of this registry
  • dcterms:language: an ISO 639-1 language
  • rdfs:seeAlso: Wikipedia articles, standards and other documentation
  • owl:deprecated and dcterms:isReplacedBy: deprecated records
